## Puter

Puter es una computadora de internet avanzada, de código abierto y autoalojable, diseñada para ser rica en funcionalidades, rápida y altamente extensible.

### Para usuarios
El objetivo de Puter es darte todo lo que necesitas para trabajar, crear y jugar en un solo lugar. Desde un simple [Notepad](https://online-notepad.com) y una [Camera](https://online-camera.com) hasta [Office Suite](https://office.puter.com) y [AI Builder](https://builder.puter.com), Puter quiere ser la solución todo en uno para tu vida digital.


### Para desarrolladores

Puter te ofrece todo lo necesario para crear y publicar aplicaciones web y juegos. Desde [IA](https://developer.puter.com/ai/) hasta [almacenamiento en la nube](https://developer.puter.com/object-storage/) y [bases de datos](https://developer.puter.com/key-value-database/), pasando por [Serverless Workers](https://developer.puter.com/serverless-workers/), Puter lo tiene cubierto. ¡Puter también te ayuda a conseguir usuarios! Una vez que crees tu aplicación, puedes publicarla en nuestra [App Store](https://apps.puter.com/) para llegar a más usuarios y monetizarla.

<br/>

## Primeros pasos


### 💻 Desarrollo local

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** Esto debería iniciar Puter en http://puter.localhost:4100

Para ejecutar este repositorio con Docker, sigue [Building from source](../self-hosting.md#building-from-source-instead-of-pulling). Crea un archivo local `docker-compose.override.yml` para seleccionar la compilación local. Mantener esta configuración fuera de `docker-compose.yml` evita conflictos al descargar actualizaciones y deja la configuración local fuera de los pull requests.


<br/>

### 🚀 Autoalojamiento

#### Linux/macOS

```bash
curl -fsSL https://puter.com/selfhost | sh
```

#### Windows

```powershell
irm https://puter.com/selfhost?os=windows | iex
```

**→** Para más detalles, consulta [Self-Hosting Puter](../self-hosting.md).
