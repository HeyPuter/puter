## Puter

Puter er en avanceret, open source og selvhostbar internetcomputer, der er designet til at være funktionsrig, hurtig og yderst udvidelig.

### For brugere
Puters mål er at give dig alt, hvad du har brug for til at arbejde, skabe og lege, under ét tag. Fra en enkel [Notepad](https://online-notepad.com) og [Camera](https://online-camera.com) til [Office Suite](https://office.puter.com) og [AI Builder](https://builder.puter.com) vil Puter være alt-i-ét-løsningen til dit digitale liv.


### For udviklere

Puter giver dig alt, hvad du skal bruge for at bygge og udgive webapps og spil. Fra [AI](https://developer.puter.com/ai/) til [cloudlagring](https://developer.puter.com/object-storage/) og [database](https://developer.puter.com/key-value-database/) til [Serverless Workers](https://developer.puter.com/serverless-workers/) har Puter dig dækket. Puter hjælper dig også med at få brugere! Når du har bygget din app, kan du udgive den i vores [App Store](https://apps.puter.com/) for at nå ud til brugere og tjene penge på den.

<br/>

## Kom godt i gang


### 💻 Lokal udvikling

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** Det burde starte Puter på http://puter.localhost:4100

Hvis du vil køre denne kopi med Docker, så følg [Building from source](../self-hosting.md#building-from-source-instead-of-pulling). Opret en lokal `docker-compose.override.yml` for at vælge det lokale build. Når disse indstillinger holdes ude af `docker-compose.yml`, undgår du konflikter, når du henter opdateringer, og holder lokal konfiguration ude af pull requests.


<br/>

### 🚀 Selvhosting

#### Linux/macOS

```bash
curl -fsSL https://puter.com/selfhost | sh
```

#### Windows

```powershell
irm https://puter.com/selfhost?os=windows | iex
```

**→** Du kan læse mere i [Self-Hosting Puter](../self-hosting.md).
