## Puter

Puter — це просунутий інтернет-комп'ютер з відкритим кодом, який можна розгорнути на власному сервері. Він створений бути багатофункціональним, швидким і дуже розширюваним.

### Для користувачів
Мета Puter — дати вам усе необхідне для роботи, творчості та розваг під одним дахом. Від простих [Notepad](https://online-notepad.com) і [Camera](https://online-camera.com) до [Office Suite](https://office.puter.com) та [AI Builder](https://builder.puter.com): Puter прагне стати універсальним рішенням для вашого цифрового життя.


### Для розробників

Puter надає все необхідне для створення та публікації вебдодатків і ігор. Від [ШІ](https://developer.puter.com/ai/) до [хмарного сховища](https://developer.puter.com/object-storage/), [бази даних](https://developer.puter.com/key-value-database/) та [безсерверних воркерів](https://developer.puter.com/serverless-workers/) — Puter має все це. Puter також допомагає знаходити користувачів! Створивши додаток, ви можете опублікувати його в нашому [App Store](https://apps.puter.com/), щоб охопити користувачів і заробляти на ньому.

## Початок роботи


### 💻 Локальна розробка

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** Це має запустити Puter за адресою http://puter.localhost:4100

Щоб запустити цю копію репозиторію через Docker, скористайтеся розділом [Building from source](../self-hosting.md#building-from-source-instead-of-pulling). Створіть локальний файл `docker-compose.override.yml`, щоб обрати локальну збірку. Якщо тримати ці налаштування поза `docker-compose.yml`, не виникатиме конфліктів під час отримання оновлень, а локальна конфігурація не потрапить у pull request'и.


<br/>

### 🚀 Self-hosting

#### Linux/macOS

```bash
curl -fsSL https://puter.com/selfhost | sh
```

#### Windows

```powershell
irm https://puter.com/selfhost?os=windows | iex
```

**→** Докладніше читайте в розділі [Self-hosting Puter](../self-hosting.md).
