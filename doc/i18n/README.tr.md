## Puter

Puter, zengin özelliklere sahip, hızlı ve son derece genişletilebilir olacak şekilde tasarlanmış, gelişmiş, açık kaynaklı ve kendi sunucunuzda barındırabileceğiniz bir internet bilgisayarıdır.

### Kullanıcılar İçin
Puter'ın amacı, çalışmak, üretmek ve eğlenmek için ihtiyacınız olan her şeyi tek çatı altında sunmaktır. Basit bir [Notepad](https://online-notepad.com) ve [Camera](https://online-camera.com) uygulamasından [Office Suite](https://office.puter.com) ve [AI Builder](https://builder.puter.com) araçlarına kadar Puter, dijital hayatınız için hepsi bir arada çözüm olmayı hedefler.


### Geliştiriciler İçin

Puter, web uygulamaları ve oyunlar oluşturmak ve yayınlamak için ihtiyacınız olan her şeyi sunar. [Yapay Zeka](https://developer.puter.com/ai/) ve [Bulut Depolama](https://developer.puter.com/object-storage/) hizmetlerinden [Veritabanı](https://developer.puter.com/key-value-database/) ve [Sunucusuz Worker'lara](https://developer.puter.com/serverless-workers/) kadar Puter yanınızda. Puter ayrıca kullanıcı bulmanıza da yardımcı olur! Uygulamanızı oluşturduktan sonra, kullanıcılara ulaşmak ve gelir elde etmek için onu [App Store](https://apps.puter.com/)'umuzda yayınlayabilirsiniz.

<br/>

## Başlarken


### 💻 Yerel Geliştirme

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** Bu, Puter'ı http://puter.localhost:4100 adresinde başlatmalıdır.

Bu kopyayı Docker ile çalıştırmak için [Building from source](../self-hosting.md#building-from-source-instead-of-pulling) bölümünü izleyin. Yerel derlemeyi seçmek için yerel bir `docker-compose.override.yml` dosyası oluşturun. Bu ayarları `docker-compose.yml` dosyasının dışında tutmak, güncellemeleri çekerken çakışmaları önler ve yerel yapılandırmanızı pull request'lerin dışında bırakır.


<br/>

### 🚀 Kendi Sunucunuzda Barındırma

#### Linux/macOS

```bash
curl -fsSL https://puter.com/selfhost | sh
```

#### Windows

```powershell
irm https://puter.com/selfhost?os=windows | iex
```

**→** Daha fazla ayrıntı için [Puter'ı Kendi Sunucunuzda Barındırma](../self-hosting.md) sayfasına bakın.
