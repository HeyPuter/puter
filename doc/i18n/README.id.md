## Puter

Puter adalah komputer internet canggih, sumber terbuka, dan dapat dihosting sendiri, yang dirancang agar kaya fitur, cepat, dan sangat mudah diperluas.

### Untuk Pengguna
Tujuan Puter adalah menyediakan semua yang Anda butuhkan untuk bekerja, berkarya, dan bermain dalam satu tempat. Mulai dari [Notepad](https://online-notepad.com) dan [Camera](https://online-camera.com) sederhana hingga [Office Suite](https://office.puter.com) dan [AI Builder](https://builder.puter.com), Puter ingin menjadi solusi serba ada untuk kehidupan digital Anda.


### Untuk Pengembang

Puter menyediakan semua yang Anda butuhkan untuk membangun dan menerbitkan aplikasi web dan permainan. Mulai dari [AI](https://developer.puter.com/ai/) hingga [Penyimpanan Cloud](https://developer.puter.com/object-storage/), [Basis Data](https://developer.puter.com/key-value-database/), dan [Serverless Workers](https://developer.puter.com/serverless-workers/), Puter siap membantu Anda. Puter juga membantu Anda mendapatkan pengguna! Setelah aplikasi Anda selesai, Anda dapat menerbitkannya di [App Store](https://apps.puter.com/) kami untuk menjangkau pengguna dan memonetisasinya.

<br/>

## Memulai


### 💻 Pengembangan Lokal

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** Ini akan menjalankan Puter di  http://puter.localhost:4100

Untuk menjalankan checkout ini dengan Docker, ikuti [Membangun dari sumber](../self-hosting.md#building-from-source-instead-of-pulling). Buat file `docker-compose.override.yml` lokal untuk memilih build lokal. Dengan menjaga pengaturan ini di luar `docker-compose.yml`, Anda menghindari konflik saat menarik pembaruan dan menjaga konfigurasi lokal tetap di luar pull request.

<br/>

### 🚀 Hosting Sendiri

#### Linux/macOS

```bash
curl -fsSL https://puter.com/selfhost | sh
```

#### Windows

```powershell
irm https://puter.com/selfhost?os=windows | iex
```

**→** Untuk detail lebih lanjut, lihat [Hosting Sendiri Puter](../self-hosting.md).
