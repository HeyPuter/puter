## Puter

Puter-ը առաջադեմ, բաց կոդով և ինքնահոսթ հնարավորությամբ ինտերնետ համակարգիչ է, որը նախագծված է լինել ֆունկցիոնալ հարուստ, արագ և բարձր ընդլայնելի։

### Օգտատերերի համար
Puter-ի նպատակն է մեկ տանիքի տակ տալ ձեզ այն ամենը, ինչ պետք է աշխատելու, ստեղծելու և խաղալու համար։ Պարզ [Notepad](https://online-notepad.com)-ից և [Camera](https://online-camera.com)-ից մինչև [Office Suite](https://office.puter.com) և [AI Builder](https://builder.puter.com)՝ Puter-ը ցանկանում է դառնալ ձեր թվային կյանքի համապարփակ լուծումը։


### Մշակողների համար

Puter-ը տրամադրում է այն ամենը, ինչ պետք է վեբ հավելվածներ և խաղեր ստեղծելու և հրապարակելու համար։ [Արհեստական բանականությունից](https://developer.puter.com/ai/) և [ամպային պահոցից](https://developer.puter.com/object-storage/) մինչև [տվյալների բազա](https://developer.puter.com/key-value-database/) և [Serverless Workers](https://developer.puter.com/serverless-workers/)՝ Puter-ն ամեն ինչ ունի։ Puter-ն օգնում է նաև օգտատերեր գտնել։ Երբ ձեր հավելվածը պատրաստ է, կարող եք հրապարակել այն մեր [App Store](https://apps.puter.com/)-ում՝ օգտատերերին հասնելու և եկամուտ ստանալու համար։

<br/>

## Սկսել


### 💻 Լոկալ ծրագրավորում

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** Սա կգործարկի Puter-ը հետևյալ հասցեով՝  http://puter.localhost:4100

Այս պահոցը Docker-ով գործարկելու համար հետևեք [Կառուցում սկզբնական կոդից](../self-hosting.md#building-from-source-instead-of-pulling) հրահանգներին։ Լոկալ build ընտրելու համար ստեղծեք լոկալ `docker-compose.override.yml`։ Այս կարգավորումները `docker-compose.yml`-ից դուրս պահելը թույլ չի տալիս հակասություններ առաջանալ թարմացումները ստանալիս և լոկալ կարգավորումները դուրս է թողնում pull request-ներից։

<br/>

### 🚀 Ինքնահոսթ

#### Linux/macOS

```bash
curl -fsSL https://puter.com/selfhost | sh
```

#### Windows

```powershell
irm https://puter.com/selfhost?os=windows | iex
```

**→** Լրացուցիչ մանրամասների համար տես [Puter-ի ինքնահոսթինգ](../self-hosting.md)։
