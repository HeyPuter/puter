## Puter

Puter একটি উন্নত, ওপেন-সোর্স ও সেল্ফ-হোস্টেবল ইন্টারনেট কম্পিউটার, যা ফিচারসমৃদ্ধ, দ্রুত এবং সহজে এক্সটেন্ড করার উপযোগী করে তৈরি।

### ব্যবহারকারীদের জন্য
কাজ, সৃজনশীলতা আর বিনোদন, সবকিছুর জন্য আপনার যা দরকার তা এক ছাদের নিচে দেওয়াই Puter-এর লক্ষ্য। একটি সাধারণ [Notepad](https://online-notepad.com) ও [Camera](https://online-camera.com) থেকে শুরু করে [Office Suite](https://office.puter.com) ও [AI Builder](https://builder.puter.com) পর্যন্ত, Puter হতে চায় আপনার ডিজিটাল জীবনের অল-ইন-ওয়ান সমাধান।


### ডেভেলপারদের জন্য

ওয়েব অ্যাপ ও গেম তৈরি এবং প্রকাশ করার জন্য যা কিছু দরকার, Puter তা-ই দেয়। [এআই](https://developer.puter.com/ai/) থেকে [ক্লাউড স্টোরেজ](https://developer.puter.com/object-storage/) ও [ডেটাবেস](https://developer.puter.com/key-value-database/), এমনকি [সার্ভারলেস ওয়ার্কার](https://developer.puter.com/serverless-workers/) পর্যন্ত সবই Puter-এ আছে। Puter আপনাকে ব্যবহারকারী পেতেও সাহায্য করে! অ্যাপ তৈরি হয়ে গেলে আমাদের [App Store](https://apps.puter.com/)-এ প্রকাশ করে ব্যবহারকারীদের কাছে পৌঁছাতে এবং আয় করতে পারবেন।

<br/>

## শুরু করুন


### 💻 লোকাল ডেভেলপমেন্ট

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** এটি Puter-কে http://puter.localhost:4100 ঠিকানায় চালু করবে

এই চেকআউট Docker দিয়ে চালাতে হলে [Building from source](../self-hosting.md#building-from-source-instead-of-pulling) অনুসরণ করুন। লোকাল বিল্ড বেছে নিতে একটি লোকাল `docker-compose.override.yml` তৈরি করুন। এই সেটিংস `docker-compose.yml`-এর বাইরে রাখলে আপডেট পুল করার সময় কনফ্লিক্ট এড়ানো যায় এবং লোকাল কনফিগারেশন পুল রিকোয়েস্টের বাইরে থাকে।


<br/>

### 🚀 সেল্ফ-হোস্টিং

#### Linux/macOS

```bash
curl -fsSL https://puter.com/selfhost | sh
```

#### Windows

```powershell
irm https://puter.com/selfhost?os=windows | iex
```

**→** আরও বিস্তারিত জানতে [Self-Hosting Puter](../self-hosting.md) দেখুন।
