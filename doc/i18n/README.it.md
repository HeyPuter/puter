## Puter

Puter è un computer internet avanzato, open source e auto-ospitabile, progettato per essere ricco di funzionalità, veloce e altamente estensibile.

### Per gli utenti
L'obiettivo di Puter è offrirti tutto ciò che ti serve per lavorare, creare e divertirti in un unico posto. Da un semplice [Notepad](https://online-notepad.com) e [Camera](https://online-camera.com) fino a [Office Suite](https://office.puter.com) e [AI Builder](https://builder.puter.com), Puter vuole essere la soluzione completa per la tua vita digitale.


### Per gli sviluppatori

Puter offre tutto ciò che serve per creare e pubblicare app web e giochi. Dall'[IA](https://developer.puter.com/ai/) al [cloud storage](https://developer.puter.com/object-storage/) e al [database](https://developer.puter.com/key-value-database/), fino ai [worker serverless](https://developer.puter.com/serverless-workers/), Puter ha tutto quello che ti serve. Puter ti aiuta anche a trovare utenti! Una volta creata la tua app, puoi pubblicarla sul nostro [App Store](https://apps.puter.com/) per raggiungere gli utenti e monetizzare.

<br/>

## Per iniziare


### 💻 Sviluppo locale

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** Questo dovrebbe avviare Puter all'indirizzo  http://puter.localhost:4100

Per eseguire questo checkout con Docker, segui [Compilazione dal codice sorgente](../self-hosting.md#building-from-source-instead-of-pulling). Crea un file `docker-compose.override.yml` locale per selezionare la build locale: tenere queste impostazioni fuori da `docker-compose.yml` evita conflitti quando scarichi gli aggiornamenti e mantiene la configurazione locale fuori dalle pull request.

<br/>

### 🚀 Self-hosting

#### Linux/macOS

```bash
curl -fsSL https://puter.com/selfhost | sh
```

#### Windows

```powershell
irm https://puter.com/selfhost?os=windows | iex
```

**→** Per maggiori dettagli, consulta [Self-hosting di Puter](../self-hosting.md).
