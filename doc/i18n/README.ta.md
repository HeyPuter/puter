## Puter

Puter என்பது மேம்பட்ட, ஓப்பன் சோர்ஸ், நீங்களே ஹோஸ்ட் செய்யக்கூடிய இன்டர்நெட் கணினி ஆகும். இது பல அம்சங்கள் நிறைந்ததாகவும், வேகமாகவும், எளிதில் விரிவாக்கக்கூடியதாகவும் வடிவமைக்கப்பட்டுள்ளது.

### பயனர்களுக்கு
வேலை செய்யவும், உருவாக்கவும், விளையாடவும் தேவையான அனைத்தையும் ஒரே இடத்தில் உங்களுக்கு வழங்குவதே Puter-இன் நோக்கம். எளிய [Notepad](https://online-notepad.com) மற்றும் [Camera](https://online-camera.com) முதல் [Office Suite](https://office.puter.com) மற்றும் [AI Builder](https://builder.puter.com) வரை, உங்கள் டிஜிட்டல் வாழ்க்கைக்கான அனைத்தும் அடங்கிய தீர்வாக இருக்க Puter விரும்புகிறது.


### டெவலப்பர்களுக்கு

வெப் செயலிகளையும் கேம்களையும் உருவாக்கி வெளியிட தேவையான அனைத்தையும் Puter வழங்குகிறது. [AI](https://developer.puter.com/ai/), [கிளவுட் ஸ்டோரேஜ்](https://developer.puter.com/object-storage/), [டேட்டாபேஸ்](https://developer.puter.com/key-value-database/) முதல் [Serverless Workers](https://developer.puter.com/serverless-workers/) வரை அனைத்தும் Puter-இல் உள்ளன. பயனர்களைப் பெறவும் Puter உதவுகிறது! உங்கள் செயலியை உருவாக்கிய பிறகு, எங்கள் [App Store](https://apps.puter.com/)-இல் வெளியிட்டு பயனர்களைச் சென்றடையலாம், அதன் மூலம் வருமானமும் ஈட்டலாம்.

<br/>

## தொடங்குதல்


### 💻 உள்ளூர் மேம்பாடு

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** இது Puter-ஐ http://puter.localhost:4100 முகவரியில் தொடங்கும்

இந்த checkout-ஐ Docker மூலம் இயக்க, [Building from source](../self-hosting.md#building-from-source-instead-of-pulling) பகுதியைப் பின்பற்றவும். உள்ளூர் build-ஐத் தேர்ந்தெடுக்க `docker-compose.override.yml` என்ற உள்ளூர் கோப்பை உருவாக்கவும். இந்த அமைப்புகளை `docker-compose.yml`-இல் சேர்க்காமல் வைத்திருப்பது, புதுப்பிப்புகளைப் பெறும்போது ஏற்படும் முரண்பாடுகளைத் தவிர்க்கும், மேலும் உள்ளூர் கட்டமைப்பு pull request-களில் சேராமல் தடுக்கும்.


<br/>
