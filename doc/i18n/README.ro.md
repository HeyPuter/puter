## Puter

Puter este un calculator avansat al internetului, open-source și găzduibil autonom, conceput să fie bogat în funcționalități, rapid și foarte extensibil.

### Pentru utilizatori
Scopul Puter este să îți ofere tot ce ai nevoie pentru a lucra, a crea și a te distra, sub același acoperiș. De la un simplu [Notepad](https://online-notepad.com) și [Camera](https://online-camera.com) până la [Office Suite](https://office.puter.com) și [AI Builder](https://builder.puter.com), Puter vrea să fie soluția completă pentru viața ta digitală.


### Pentru dezvoltatori

Puter îți oferă tot ce ai nevoie pentru a construi și publica aplicații web și jocuri. De la [AI](https://developer.puter.com/ai/) la [stocare în cloud](https://developer.puter.com/object-storage/) și [baze de date](https://developer.puter.com/key-value-database/), până la [workeri serverless](https://developer.puter.com/serverless-workers/), Puter te acoperă. Puter te ajută și să obții utilizatori! După ce ți-ai construit aplicația, o poți publica în [App Store](https://apps.puter.com/) pentru a ajunge la utilizatori și a câștiga bani de la ei.

<br/>

## Primii pași


### 💻 Dezvoltare locală

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** Aceasta ar trebui să pornească Puter la adresa http://puter.localhost:4100

Pentru a rula acest checkout cu Docker, urmează [Building from source](../self-hosting.md#building-from-source-instead-of-pulling). Creează un fișier local `docker-compose.override.yml` pentru a selecta build-ul local. Dacă ții aceste setări în afara `docker-compose.yml`, eviți conflictele la actualizări, iar configurația locală nu ajunge în pull request-uri.


<br/>

### 🚀 Găzduire autonomă

#### Linux/macOS

```bash
curl -fsSL https://puter.com/selfhost | sh
```

#### Windows

```powershell
irm https://puter.com/selfhost?os=windows | iex
```

**→** Pentru mai multe detalii, consultă [Găzduirea autonomă a Puter](../self-hosting.md).
