## Puter

Puter ialah komputer internet termaju, sumber terbuka dan boleh dihoskan sendiri, yang direka untuk kaya dengan ciri, pantas dan sangat boleh diluaskan.

### Untuk Pengguna
Matlamat Puter adalah untuk menyediakan segala yang anda perlukan untuk bekerja, mencipta dan bermain di bawah satu bumbung. Daripada [Notepad](https://online-notepad.com) dan [Camera](https://online-camera.com) yang ringkas kepada [Office Suite](https://office.puter.com) dan [AI Builder](https://builder.puter.com), Puter mahu menjadi penyelesaian serba lengkap untuk kehidupan digital anda.


### Untuk Pembangun

Puter menyediakan segala yang anda perlukan untuk membina dan menerbitkan apl web dan permainan. Daripada [AI](https://developer.puter.com/ai/) kepada [Storan Awan](https://developer.puter.com/object-storage/), [Pangkalan Data](https://developer.puter.com/key-value-database/) dan [Pekerja Tanpa Pelayan](https://developer.puter.com/serverless-workers/), Puter menyediakan semuanya. Puter turut membantu anda mendapatkan pengguna! Setelah anda membina apl anda, anda boleh menerbitkannya di [App Store](https://apps.puter.com/) kami untuk menjangkau pengguna dan menjana pendapatan.

<br/>

## Bermula


### 💻 Pembangunan Setempat

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** Ini akan melancarkan Puter di http://puter.localhost:4100

Untuk menjalankan checkout ini dengan Docker, ikuti [Membina daripada sumber](../self-hosting.md#building-from-source-instead-of-pulling). Cipta `docker-compose.override.yml` setempat untuk memilih binaan setempat. Dengan tidak meletakkan tetapan ini dalam `docker-compose.yml`, anda mengelakkan konflik apabila menarik kemas kini dan memastikan konfigurasi setempat tidak masuk ke dalam pull request.


<br/>

### 🚀 Hos Sendiri

#### Linux/macOS

```bash
curl -fsSL https://puter.com/selfhost | sh
```

#### Windows

```powershell
irm https://puter.com/selfhost?os=windows | iex
```

**→** Untuk butiran lanjut, lihat [Menghoskan Puter Sendiri](../self-hosting.md).
