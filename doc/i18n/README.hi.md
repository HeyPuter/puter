## Puter

Puter एक एडवांस्ड, ओपन-सोर्स और सेल्फ-होस्टेबल इंटरनेट कंप्यूटर है, जिसे फीचर-रिच, तेज़ और बेहद एक्सटेंडेबल बनाने के लिए डिज़ाइन किया गया है।

### यूज़र्स के लिए
Puter का लक्ष्य आपको काम करने, कुछ नया बनाने और खेलने के लिए ज़रूरी हर चीज़ एक ही छत के नीचे देना है। एक साधारण [Notepad](https://online-notepad.com) और [Camera](https://online-camera.com) से लेकर [Office Suite](https://office.puter.com) और [AI Builder](https://builder.puter.com) तक, Puter आपकी डिजिटल ज़िंदगी का ऑल-इन-वन समाधान बनना चाहता है।


### डेवलपर्स के लिए

Puter वेब ऐप्स और गेम्स बनाने और पब्लिश करने के लिए ज़रूरी सब कुछ देता है। [AI](https://developer.puter.com/ai/) से लेकर [क्लाउड स्टोरेज](https://developer.puter.com/object-storage/), [डेटाबेस](https://developer.puter.com/key-value-database/) और [सर्वरलेस वर्कर्स](https://developer.puter.com/serverless-workers/) तक, Puter में सब कुछ मौजूद है। Puter आपको यूज़र्स पाने में भी मदद करता है! अपना ऐप बनाने के बाद, आप उसे हमारे [App Store](https://apps.puter.com/) पर पब्लिश करके यूज़र्स तक पहुँच सकते हैं और उससे कमाई कर सकते हैं।

<br/>

## शुरुआत कैसे करें


### 💻 लोकल डेवलपमेंट

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** इससे Puter यहाँ लॉन्च होना चाहिए:  http://puter.localhost:4100

इस चेकआउट को Docker के साथ चलाने के लिए [सोर्स से बिल्ड करना](../self-hosting.md#building-from-source-instead-of-pulling) देखें। लोकल बिल्ड चुनने के लिए एक लोकल `docker-compose.override.yml` बनाएँ। इन सेटिंग्स को `docker-compose.yml` से बाहर रखने पर अपडेट खींचते समय कॉन्फ्लिक्ट नहीं होते और लोकल कॉन्फ़िगरेशन पुल रिक्वेस्ट से बाहर रहता है।

<br/>

### 🚀 सेल्फ-होस्टिंग

#### Linux/macOS

```bash
curl -fsSL https://puter.com/selfhost | sh
```

#### Windows

```powershell
irm https://puter.com/selfhost?os=windows | iex
```

**→** अधिक जानकारी के लिए [Puter को सेल्फ-होस्ट करना](../self-hosting.md) देखें।
