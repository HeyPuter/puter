## Puter

Puter คือคอมพิวเตอร์อินเทอร์เน็ตขั้นสูงแบบโอเพ่นซอร์สที่โฮสต์เองได้ ออกแบบมาให้มีฟีเจอร์ครบครัน รวดเร็ว และขยายต่อยอดได้สูง

### สำหรับผู้ใช้
เป้าหมายของ Puter คือมอบทุกสิ่งที่คุณต้องการสำหรับการทำงาน การสร้างสรรค์ และการเล่นสนุกไว้ในที่เดียว ตั้งแต่ [Notepad](https://online-notepad.com) และ [Camera](https://online-camera.com) แบบเรียบง่าย ไปจนถึง [Office Suite](https://office.puter.com) และ [AI Builder](https://builder.puter.com) Puter ต้องการเป็นโซลูชันครบวงจรสำหรับชีวิตดิจิทัลของคุณ


### สำหรับนักพัฒนา

Puter มอบทุกสิ่งที่คุณต้องการสำหรับการสร้างและเผยแพร่เว็บแอปและเกม ตั้งแต่ [AI](https://developer.puter.com/ai/) ไปจนถึง [พื้นที่เก็บข้อมูลบนคลาวด์](https://developer.puter.com/object-storage/) และ [ฐานข้อมูล](https://developer.puter.com/key-value-database/) รวมถึง [Serverless Workers](https://developer.puter.com/serverless-workers/) Puter ครอบคลุมให้คุณแล้ว นอกจากนี้ Puter ยังช่วยให้คุณหาผู้ใช้ได้ด้วย! เมื่อสร้างแอปเสร็จแล้ว คุณสามารถเผยแพร่บน [App Store](https://apps.puter.com/) ของเรา เพื่อเข้าถึงผู้ใช้และสร้างรายได้

<br/>

## การเริ่มต้นใช้งาน


### 💻 การพัฒนาในเครื่อง

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** คำสั่งนี้จะเปิด Puter ที่ http://puter.localhost:4100

หากต้องการรันโค้ดที่เช็กเอาต์นี้ด้วย Docker ให้ทำตาม [Building from source](../self-hosting.md#building-from-source-instead-of-pulling) สร้างไฟล์ `docker-compose.override.yml` ในเครื่องเพื่อเลือกใช้บิลด์ในเครื่อง การแยกการตั้งค่าเหล่านี้ออกจาก `docker-compose.yml` ช่วยหลีกเลี่ยงความขัดแย้งเมื่อดึงอัปเดต และไม่ทำให้การตั้งค่าในเครื่องปะปนไปกับ pull request


<br/>

### 🚀 การโฮสต์เอง

#### Linux/macOS

```bash
curl -fsSL https://puter.com/selfhost | sh
```

#### Windows

```powershell
irm https://puter.com/selfhost?os=windows | iex
```

**→** ดูรายละเอียดเพิ่มเติมได้ที่ [การโฮสต์ Puter เอง](../self-hosting.md)
