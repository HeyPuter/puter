## Puter

O Puter é um computador da internet avançado, de código aberto e auto-hospedável, projetado para ser rico em recursos, rápido e altamente extensível.

### Para Usuários
O objetivo do Puter é oferecer tudo o que você precisa para trabalhar, criar e se divertir em um só lugar. Desde um simples [Notepad](https://online-notepad.com) e [Camera](https://online-camera.com) até o [Office Suite](https://office.puter.com) e o [AI Builder](https://builder.puter.com), o Puter quer ser a solução completa para a sua vida digital.


### Para Desenvolvedores

O Puter oferece tudo o que você precisa para criar e publicar aplicativos web e jogos. De [IA](https://developer.puter.com/ai/) a [armazenamento em nuvem](https://developer.puter.com/object-storage/) e [banco de dados](https://developer.puter.com/key-value-database/), passando por [workers serverless](https://developer.puter.com/serverless-workers/), o Puter tem tudo isso. O Puter também ajuda você a conquistar usuários! Depois de criar seu aplicativo, você pode publicá-lo na nossa [App Store](https://apps.puter.com/) para alcançar e monetizar usuários.

## Primeiros Passos


### 💻 Desenvolvimento Local

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** Isso deve iniciar o Puter em http://puter.localhost:4100

Para executar este checkout com Docker, siga as instruções de [Building from source](../self-hosting.md#building-from-source-instead-of-pulling). Crie um arquivo local `docker-compose.override.yml` para selecionar o build local. Manter essas configurações fora do `docker-compose.yml` evita conflitos ao baixar atualizações e mantém a configuração local fora dos pull requests.


<br/>

### 🚀 Auto-Hospedagem

#### Linux/macOS

```bash
curl -fsSL https://puter.com/selfhost | sh
```

#### Windows

```powershell
irm https://puter.com/selfhost?os=windows | iex
```

**→** Para mais detalhes, consulte [Auto-Hospedagem do Puter](../self-hosting.md).

<br/>

### ☁️ Puter.com

O Puter está disponível como um serviço hospedado em [**puter.com**](https://puter.com).
