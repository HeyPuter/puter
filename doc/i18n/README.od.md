## Puter

Puter ଏକ ଉନ୍ନତ, ଖୋଲା-ମୂଳ, ସ୍ୱୟଂ-ହୋଷ୍ଟ କରିହେଉଥିବା ଇଣ୍ଟରନେଟ୍ କମ୍ପ୍ୟୁଟର, ଯାହା ବିଶେଷତାରେ ଭରପୂର, ଦ୍ରୁତ ଓ ଅତ୍ୟଧିକ ସମ୍ପ୍ରସାରଣୀୟ ଭାବେ ପ୍ରସ୍ତୁତ।

### ଉପଯୋଗକର୍ତ୍ତାଙ୍କ ପାଇଁ
କାମ କରିବା, ସୃଷ୍ଟି କରିବା ଓ ଖେଳିବା ପାଇଁ ଆପଣଙ୍କୁ ଯାହା ଆବଶ୍ୟକ, ସବୁ ଗୋଟିଏ ଛାତତଳେ ଦେବା Puter ର ଲକ୍ଷ୍ୟ। ସରଳ [Notepad](https://online-notepad.com) ଓ [Camera](https://online-camera.com) ଠାରୁ [Office Suite](https://office.puter.com) ଓ [AI Builder](https://builder.puter.com) ପର୍ଯ୍ୟନ୍ତ, Puter ଆପଣଙ୍କ ଡିଜିଟାଲ୍ ଜୀବନ ପାଇଁ ସର୍ବାଙ୍ଗୀଣ ସମାଧାନ ହେବାକୁ ଚାହେଁ।


### ଡେଭେଲପର୍ମାନଙ୍କ ପାଇଁ

Puter ୱେବ୍ ଆପ୍ ଓ ଗେମ୍ ତିଆରି ଏବଂ ପ୍ରକାଶ କରିବା ପାଇଁ ଆବଶ୍ୟକ ସବୁକିଛି ଦିଏ। [AI](https://developer.puter.com/ai/) ଠାରୁ [କ୍ଲାଉଡ୍ ଷ୍ଟୋରେଜ୍](https://developer.puter.com/object-storage/) ଓ [ଡାଟାବେସ୍](https://developer.puter.com/key-value-database/) ଏବଂ [ସର୍ଭରଲେସ୍ ୱାର୍କର୍ସ](https://developer.puter.com/serverless-workers/) ପର୍ଯ୍ୟନ୍ତ, Puter ସବୁ ଦେଇଥାଏ। Puter ଆପଣଙ୍କୁ ଉପଯୋଗକର୍ତ୍ତା ପାଇବାରେ ମଧ୍ୟ ସାହାଯ୍ୟ କରେ! ଆପଣ ଆପ୍ ତିଆରି କରିସାରିଲେ, ଆମର [App Store](https://apps.puter.com/)ରେ ପ୍ରକାଶ କରି ଉପଯୋଗକର୍ତ୍ତାଙ୍କ ପାଖରେ ପହଞ୍ଚିପାରିବେ ଏବଂ ଆୟ କରିପାରିବେ।

## ଆରମ୍ଭ କରିବା


### 💻 ସ୍ଥାନୀୟ ବିକାଶ

```bash
git clone https://github.com/HeyPuter/puter
cd puter
npm install
npm start
```
**→** ଏହା http://puter.localhost:4100 ରେ Puter ଆରମ୍ଭ କରିବ

Docker ସହିତ ଏହି ଚେକଆଉଟ୍ ଚଲାଇବାକୁ, [ସୋର୍ସରୁ ବିଲ୍ଡ୍ କରିବା](../self-hosting.md#building-from-source-instead-of-pulling) ଅନୁସରଣ କରନ୍ତୁ। ସ୍ଥାନୀୟ ବିଲ୍ଡ୍ ବାଛିବା ପାଇଁ ଏକ ସ୍ଥାନୀୟ `docker-compose.override.yml` ତିଆରି କରନ୍ତୁ। ଏହି ସେଟିଂସ୍‌କୁ `docker-compose.yml` ବାହାରେ ରଖିଲେ ଅପଡେଟ୍ ଆଣିବା ସମୟରେ ଦ୍ୱନ୍ଦ୍ୱ ଏଡ଼ାଯାଏ ଏବଂ ସ୍ଥାନୀୟ ବିନ୍ୟାସ ପୁଲ୍ ରିକ୍ୱେଷ୍ଟରେ ମିଶେ ନାହିଁ।


<br/>

### 🚀 ସ୍ୱୟଂ-ହୋଷ୍ଟିଂ

