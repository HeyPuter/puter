Hides the window of your application.

## Syntax

```javascript
puter.ui.hideWindow()
```

## Parameters

None.

## Return value

None.

## Examples

### Hide the app's window

```html
<html>
<body>
    <script src="https://js.puter.com/v2/"></script>
    <script>
        puter.ui.hideWindow();
    </script>
</body>
</html>
```
